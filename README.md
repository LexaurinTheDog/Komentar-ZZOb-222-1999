# Komentář k zákonu č. 222/1999 Sb., o zajišťování obrany České republiky

Otevřený komentář k zákonu o zajišťování obrany České republiky — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; řízení a organizace obrany státu, působnost vlády, Ministerstva obrany, krajů a obcí, povinnosti osob, věcné prostředky a pracovní povinnost, objekty důležité pro obranu státu, vojenské újezdy, financování obrany a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1999-00222_2025-07-01`.
